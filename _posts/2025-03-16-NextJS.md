# Inventory Management API with NestJS

This repository implements a **NestJS-based Inventory Management API** designed to efficiently handle CRUD operations for managing items in an inventory system. It's written in TypeScript and includes extensive testing with both unit and end-to-end (e2e) tests.

## Overview

The API provides endpoints to:

- **Fetch inventory items** by their ID or name.
- **Create new items** and add them to the inventory.
- **Update existing items** with new attributes.
- **Delete items** from the inventory.

The project leverages **NestJS**, a progressive Node.js framework that emphasizes TypeScript support, scalability, and developer productivity. It uses **Swagger** for API documentation and facilitates interactive API testing directly within the documentation interface.

## API Documentation

The API documentation is auto-generated with **Swagger** and is accessible at `/api` once the application is running. It includes details for every available endpoint, request parameters, and expected responses.

### Example Endpoints

1. **Get an Item**
   - **Endpoint:** `GET /get-item/:itemId`
   - **Description:** Fetches an item by its `itemId`. You can optionally filter by item `name`.
   - **Parameters:**
     - `itemId`: The ID of the item (path parameter).
     - `name`: Optional filter for the item's name (query parameter).
   - **Response:**
     ```json
     {
       "name": "Apple",
       "price": 1.99,
       "description": "A fresh red apple"
     }
     ```

2. **Create an Item**
   - **Endpoint:** `POST /create-item/:itemId`
   - **Description:** Adds a new item to the inventory.
   - **Request Body:**
     ```json
     {
       "name": "Banana",
       "price": 0.99,
       "description": "A ripe banana"
     }
     ```
   - **Response:**
     ```json
     {
       "name": "Banana",
       "price": 0.99,
       "description": "A ripe banana"
     }
     ```

3. **Update an Item**
   - **Endpoint:** `PUT /update-item/:itemId`
   - **Description:** Updates details of an existing item in the inventory.
   - **Request Body:**
     ```json
     {
       "name": "Green Banana"
     }
     ```
   - **Response:**
     ```json
     {
       "name": "Green Banana",
       "price": 0.99,
       "description": "A ripe banana"
     }
     ```

4. **Delete an Item**
   - **Endpoint:** `DELETE /delete-item/:itemId`
   - **Description:** Removes an item from the inventory.
   - **Response:**
     ```json
     {
       "Success": "Item deleted!"
     }
     ```

## Installation and Setup

Clone the repository and install dependencies:

```bash
$ npm install
```
# Running the Application

Start the application in development mode:

```bash
$ npm run start
```
For continuous development with hot-reloading:

```bash
$ npm run start:dev
```

# Testing
Run unit tests to ensure that the service methods and logic function as expected:

```bash
$ npm run test
```

Run end-to-end tests:

```Bash
$ npm run test:e2e
```

Generate a test coverage report:

```Bash
$ npm run test:cov
```
